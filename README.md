# Regional Growth Analysis

## Project Overview
This project analyzes regional sales performance and growth trends using the Sample Superstore dataset. The analysis focuses on monthly sales, month-over-month (MoM) growth, and regional performance to identify business opportunities and understand sales patterns.

## Objectives
- Analyze monthly sales across different regions.
- Calculate month-over-month sales growth.
- Compare sales and profit performance by region.
- Identify high-performing and low-performing regions.
- Generate insights to support business decisions.

## Tools & Technologies
- **Microsoft SQL Server (SSMS):** Data analysis and SQL queries.
- **Microsoft Excel:** Data analysis, calculations, charts, and reporting.
- **Dataset:** Sample Superstore CSV.

## Dataset Details
The dataset contains order-level information, including:
- Order ID and Order Date
- Region, State, and City
- Product Category and Sub-Category
- Sales, Quantity, Discount, and Profit

## Analysis Performed
1. Monthly regional sales analysis.
2. Month-over-month sales growth calculation using SQL window functions.
3. Regional sales and profit comparison.
4. Identification of regional sales trends.
5. Preparation of charts and key business insights.

## Key Findings
- The West region recorded the highest total sales.
- The East region ranked second in total sales.
- The Central and South regions recorded comparatively lower total sales.
- Monthly sales trends showed variations across all four regions.
- Regional performance analysis can help identify opportunities for improving sales.

## Project Files
- `Regional_Growth_Analysis.sql` – SQL queries used for analysis.
- `Regional_Growth_Analysis_Completed.xlsx` – Completed Excel analysis and charts.
- `Sample - Superstore.csv` – Original dataset.
- `Regional_Growth_Analysis_Project_Report.docx` – Detailed project report.

## Conclusion
This project demonstrates how SQL and Excel can be used together to analyze regional sales performance and monthly growth trends. The findings provide useful insights for identifying strong-performing regions and planning future business strategies.
